# The Measure — Rev52 / Dual RSS Discovery

The website now advertises two RSS feeds in its HTML head and footer:

- `feed.xml` — RSS: ALL
- `feed-heavy.xml` — RSS: RESEARCH

No changes to navigation, homepage selection, article rendering, ticker, masthead, or Lower Register.

Install at the website repository root over `index.html`. Publish the second feed by installing SNIPE Rev52 and running **Build SEO pages + sitemap**. The site overlay alone does not create XML feed files.
